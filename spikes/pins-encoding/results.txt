== A2c. Where the Lean cost is: `#u8`, not `Array.make`'s `hl` ==
spikes/pins-encoding/patch_hl.py rewrites the generated `Array.make ... [ ... ]`
to pass `hl` explicitly; lean on the 5x1700-byte model:

  hl by the default `by simp`  55.3s
  hl `(by rfl)`                50.8s
  hl `(sorry)`                 52.3s

so the side condition is not the cost (it is only why the default maxRecDepth
2048 fails above ~256 elements -- `-max-recdepth` fixes that).  The cost is the
element notation (spikes/pins-encoding/u8ab.sh), same 1700 bytes:

  `def x : List Std.U8  := [99#u8, ...]`  instr= 98.2G user=11.2s
  `def y : List UInt8   := [99, ...]`     instr=  9.8G user= 1.3s
                                          (both include ~1.2s of `import Aeneas`)

~100x per element.  That single factor is three quarters of route A's cost.

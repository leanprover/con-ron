# scripts/provenance-skip.txt — THE DELIBERATE SKIPS (task #33, DESIGN.md §3.7)
#
# The ledger (`scripts/provenance.py coverage`, and through it
# `scripts/progress.py`) counts a con-leche declaration as *to be ported*
# unless it is listed here.  One line per declaration:
#
#     <con-leche-relative Lean path> <declaration> <reason>
#
# `<declaration>` may be `*`, which covers every declaration of that file.
# The reason is the rest of the line and is MANDATORY: a skip with no reason
# is a hole in the ledger, and `coverage` reports it as MALFORMED.  `coverage`
# also reports a skip that names no declaration of the file (STALE) and one
# whose declaration *is* cited after all (REDUNDANT), so the list cannot rot
# quietly.  Whatever is not here and not cited shows up as `uncovered`.
#
# This file is the machine-readable form of the task log's "Deliberately not
# ported" sections; every entry's long argument is in the Rust module note of
# the module that would have held it.  It does NOT affect
# `scripts/provenance.py check`, which is about the Rust side.

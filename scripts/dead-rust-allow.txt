# scripts/dead-rust-allow.txt — the dead-rust.py allowlist (task #105 sweep).
#
# `scripts/dead-rust.py --check` lists every `pub` item with no non-test use
# it can find and fails if any of them is not named here.  One line per item:
#
#     <file>:<name>	<reason>
#
# (`<file>` and `<name>` exactly as `dead-rust.py` prints them, a real tab
# before the reason.)  Two kinds of entry, and every line below says which:
#
# (A) LIVE, but only from a Lean proof or the extraction pipeline, never from
#     another Rust call site — Aeneas still needs the function to exist so
#     its extracted Lean name is there to state a theorem about, or the
#     function is deliberately the "entry point" twin of a con-leche
#     declaration even though the checker's own hot path goes through an
#     internal `knot_*`/handle-native version instead.  Deleting it would
#     make a live headline theorem (grep `proof/ConRon/{Refine,Refine2,
#     Bridge,Capstone}*`) fail to even state, or would drop a con-leche
#     citation with nothing to replace it.
#
# (B) A `dead-rust.py` FALSE POSITIVE: the item has a real, ordinary Rust
#     caller, but the census's per-line, no-alias heuristic cannot see it.
#     Two recurring shapes, both noted in the script's own docstring as
#     heuristic limits:
#       - the name is not unique in the workspace (defined in more than one
#         module) and the only call site imports it through a *multi-line*
#         `use crate::mod::{ ..., name, ... };` (the module path and the name
#         land on different physical lines, so the single-line regex never
#         sees them together) or through a module alias (`use crate::kernel::
#         trust_axioms as ctrust;`, then `ctrust::name(...)`);
#       - the call is `receiver.name(...)` dot syntax on a struct method
#         whose name collides with another type's method of the same name
#         (`HashMap`/`HashMap2`/`Caches`/`Memos`/`EStore` all have their own
#         `reset`/`view_n`/`insert`/…), so no line contains `mod::name` at
#         all.
#     Verified by hand (grep for the real call site) or by `cargo build`
#     itself failing with "no method/function named `name` found" when the
#     item was actually deleted; the entry names the real caller.
#
# Test-only items ("only-tests" in `dead-rust.py`'s own report) are NOT
# blanket-listed here as dead weight: several of them are differential or
# regression test infrastructure for code that IS live (arena/frontend/ron),
# verified the same way — read the test, see what it actually checks, and
# only list it if the test gives it real, ongoing value.  Kernel-tier
# ("the old retired Expr-tree/`cached` checker") only-tests items with no
# such value were deleted along with their tests in this sweep instead of
# being listed here; what remains below is what a live test still exercises.

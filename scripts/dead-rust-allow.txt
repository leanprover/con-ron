# scripts/dead-rust-allow.txt — the dead-rust.py allowlist (task #105 sweep).
#
# `scripts/dead-rust.py --check` lists every `pub` item with no non-test use
# it can find and fails if any of them is not named here.  One line per item:
#
#     <file>:<name>	<reason>
#
# (`<file>` and `<name>` exactly as `dead-rust.py` prints them, a real tab
# before the reason.)  An item belongs here only if it is LIVE although no
# Rust calls it: a live Lean statement (grep `proof/ConRon` outside
# `Generated/`, and the statement must itself be used — see
# `scripts/dead-census.py`) names its extracted definition, so deleting it
# would make that statement fail to even elaborate.
#
# Not here, by design (task #105 R-SWEEP2):
#   * `dead-rust.py` false positives — fix the script instead (it resolves
#     `use` groups across lines, `use … as` aliases, and methods through the
#     types a file mentions; `--why <name>` shows what it counted);
#   * items only tests use — a test of dead code is dead code, so the item
#     and its test go; an item that is the ORACLE a test checks a live
#     function against moves into that test module as a private helper.

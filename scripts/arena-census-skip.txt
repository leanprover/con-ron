# scripts/arena-census-skip.txt — THE ARENA CENSUS'S DELIBERATE SKIPS
# (task #97-CENSUS; `scripts/arena-census.py`, DESIGN.md §8)
#
# `scripts/arena-census.py` counts every top-level `def` of
# `proof/ConRon/Arena/**` as a twin that OWES a bridge theorem (T1) and a
# refinement theorem (T2) — unless it is listed here, with a reason.  One
# line per definition:
#
#     <repo-relative Lean path> <definition|*> <T1|T2|BOTH> <reason>
#
# `<definition>` may be `*`, which covers every definition of that file.
# The scope says WHICH of the two theorems is not owed; the reason is the
# rest of the line and is MANDATORY.  A line with no reason, or with a scope
# that is not one of the three words, is reported as MALFORMED; a line that
# names no definition of its file as STALE; a line whose twin turns out to be
# stated after all as REDUNDANT.  So the list cannot rot quietly, and "not
# stated" is never silent — which is the whole point of having it.
#
# The classes are `proof/ConRon/Arena/CENSUS.md`'s: **(P)** is pure data with
# no term inside, copied verbatim, whose bridge obligation would be `rfl`;
# **(S)** is skipped in the Rust port with the reason
# `scripts/provenance-skip.txt` gives.  A (P) or (S) twin still needs a line
# HERE, because this census's subject is the arena's own Lean and not
# con-leche's.
#
# Everything NOT listed here and not stated is genuine open work, and
# `scripts/arena-census.py --open` is the list of it.
